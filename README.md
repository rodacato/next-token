# Next Token

An interactive course on large language models, from the inside out, set in a
letterpress print shop where every token is set by hand.

Status: **Step 0 — visual direction.** Three divergent boards and an animated
prototype live in [`design/step-0/`](design/step-0/). Nothing is built yet.

## Looking at the boards

```bash
npm install
npm run boards
```

Then open <http://localhost:4173/design/step-0/>.
